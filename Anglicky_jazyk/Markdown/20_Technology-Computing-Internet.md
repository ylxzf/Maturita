## Technology Overview

### Definition & Evolution
- **Technology**: Application of knowledge to solve problems
- **Origins**: Stone tools (Paleolithic era)
- **Key Milestones**:
  - Fire mastery (~1.5M BCE)
  - Wheel invention (~3500 BCE)
  - Steam engine (Watt, 1776)
  - Electricity (19th century)
  - Digital revolution (20th century)

### Computing History
- **First Modern Computer**:
  - ENIAC (1945)
  - Created for atomic bomb calculations
  - Room-sized with vacuum tubes
- **Key Figures**:
  - John von Neumann (architecture)
  - Alan Turing (theoretical foundations)

## Modern Computing

### Device Types
| Category | Examples | Use Cases |
|----------|----------|-----------|
| **Mainframes** | IBM Z Series | Banking, research |
| **Personal Computers** | Desktops, laptops | Work/education |
| **Mobile Devices** | Tablets, smartphones | Everyday use |

### System Components
- **Hardware**:
  - Processor (CPU - "computer brain")
  - Memory (RAM/ROM)
  - Storage (HDD/SSD)
  - Peripherals (input/output devices)
- **Software**:
  - Operating Systems (Windows, Linux, macOS)
  - Applications (productivity, creative, utility)

### Networks
- **LAN** (Local Area Network)
- **MAN** (Metropolitan Area Network)
- **WAN** (Wide Area Network - Internet)
